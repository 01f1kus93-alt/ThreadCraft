# ThreadCraft

**ThreadCraft** — многопоточный воксельный движок в стиле Minecraft, написанный на C++20 с использованием **raylib**. Основной упор сделан на производительность: генерация чанков, построение мешей и загрузка текстур выполняются параллельно в пуле потоков, а для оптимизации геометрии используется **Greedy Meshing** с кастомными GLSL-шейдерами.

---

## Возможности

### ⚙️ Многопоточное ядро
- **ThreadPool** — пул рабочих потоков с приоритетной очередью задач.
- Генерация чанков, построение мешей и выгрузка на GPU выполняются асинхронно.
- Количество потоков определяется автоматически (`hardware_concurrency`), минимум 4.
- **Лимиты очередей** — при переполнении новые задачи не добавляются, что защищает ОЗУ от бесконтрольного роста при быстром полёте.
- **Сортировка по приоритету** — чанки ближе к игроку обрабатываются раньше; при наличии вектора скорости приоритет смещается в направлении движения.

### 🏗️ Greedy Meshing
- Оптимизация геометрии: соседние грани блоков с одинаковой текстурой сливаются в один крупный прямоугольник.
- **Кастомный шейдер** (`greedy.vs` / `greedy.fs`) — UV-координаты и индекс текстуры передаются через vertex colors, что позволяет шейдеру правильно затайлить текстуру на объединённой грани без увеличения числа вершин.
- Прозрачные блоки (стекло, листва, вода) рендерятся отдельным проходом.

### 🌍 Процедурная генерация мира
- **Высота рельефа** — 2D-шум Перлина (определяет высоту точки) с нормализацией FBm.
- **Горы** — плавное усиление амплитуды на высоких пиках (биом Mountains).
- **Пещеры** — объёмный 3D-шум с двумя червеобразными проходами (worm-пещеры).
- **Ленивая генерация пещер** — пещеры генерируются только в чанках, находящихся ближе 22 чанков к игроку. Далёкие чанки содержат сплошной камень, что экономит ~30–50 % времени генерации на больших дистанциях прорисовки.
- **Входы в пещеры** — мягкие спуски с поверхности (трава/земля заменяются на воздух).
- **Слои**: бедрок с шумовым искажением (1–6 слоёв), глубинный сланец (y ≤ 15), камень, земля/песок (4 блока под поверхностью), трава/песок на поверхности, вода ниже уровня моря.
- **Руды** — уголь (16–96), железо (16–48), золото (глубинный сланец) генерируются на основе 3D-шума.
- **Деревья** — 4–6 блоков ствола + крона из листвы со случайными пропусками; биомные вариации (дуб, берёза). Пустыни и океаны без деревьев.
- **Биомы** — равнины, горы, пустыни, океан, берёзовый лес; определяются по высоте, температуре и влажности.
- Размер чанка: 16×256×16 блоков; секции по 16 блоков по Y с ленивым выделением памяти для пустых секций.

### 🎮 Игровые механики
- **Режимы игры**: Creative, Survival, Adventure, Spectator.
  - Переключение — удержание `F3` + нажатие `F4` (как в ванильном Minecraft 1.20).
  - В **Spectator** — ноклип, утроенная скорость полёта; блоки не ломаются и не ставятся.
  - В **Creative** — мгновенное ломание, бесконечные блоки, полёт.
  - В **Survival** — ломание с прогрессом (зависит от прочности блока), дропы предметов.
- **Свободный полёт** (FlyCamera) — WASD + мышь, Shift ускоряет, Ctrl замедляет.
- **Ломание блоков** — удержание ЛКМ (прогресс зависит от прочности, трещины `destroy_stage_0..9`).
- **Установка блоков** — ПКМ (ставится блок из выбранного слота hotbar; в Survival блок расходуется).
- **Пипетка** — средняя кнопка мыши (копирует блок под прицелом в выбранный слот).
- **Инвентарь** — 9 слотов hotbar + 27 основных, drag&drop, ПКМ = половина/1, клик вне слотов = выброс.
- **Дропы** — сломанный блок выпадает предметом, подбирается при подходе (радиус 1.5 блока, задержка 0.35 с).
- **Партиклы** — частицы ломания/удара, цвет = центр текстуры блока ±5 на канал (до 2048 частиц).
- **Рэйкаст** — точное определение блока, на который смотрит игрок, с подсветкой рамкой.
- **Здоровье** — 10 сердец (20 HP), падение с высоты > 3 блоков наносит урон (в Survival).
- **Меню паузы** — `Esc`: настройки дальности прорисовки (слайдер), FOV (слайдер), слоёв листвы, выход.

### 🎨 Рендеринг
- **Texture Atlas** — все текстуры блоков объединены в единый атлас 16×16 тайлов.
- **Padding** — 8 px отступа между тайлами для устранения артефактов при mip-mapping.
- **Frustum Culling** — невидимые чанки не отправляются на отрисовку.
- **Underground Culling** — на дистанции > 16 чанков чанки, целиком находящиеся ниже минимальной высоты рельефа, не рендерятся (ускорение на больших дистанциях).
- **Туман** — far plane привязан к дальности прорисовки; туман начинается с 50 % дистанции.
- **Leaves LOD** — на дистанции > 16 чанков листва рендерится сплошным непрозрачным зелёным цветом вместо alpha-discard; настраивается количество «дырявых» слоёв кроны.
- **Memory HUD** —左上角 использование оперативной памяти процесса / всего системы (обновляется раз в секунду, Linux `/proc`).
- **Оконный режим** — изменяемый размер окна.
- **HUD**: FPS, число чанков в памяти, координаты камеры, ID выбранного блока, график времени кадра (последние 120 кадров).
- **Отрисовка полоски здоровья** — 10 сердец слева над hotbar (vanilla-стиль, из `icons.png`).

## Сборка и запуск

### Зависимости
- **CMake** ≥ 3.20
- **raylib** (системная установка: `make install`, vcpkg или `apt install libraylib-dev`)
- **Компилятор C++20** (GCC 11+, Clang 14+, MSVC 2022+)

### Linux (Debian/Ubuntu)
```bash
sudo apt install cmake build-essential libraylib-dev
```

### Сборка
```bash
cd threadcraft
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
```

### Запуск
```bash
./minecraft_clone
```

## Производительность

- **Автоматический пул потоков**: количество рабочих потоков = `max(4, hardware_concurrency - 1)`.
- **Приоритетная очередь задач**: чанки ближе к игроку обрабатываются раньше.
- **Асинхронная загрузка на GPU**: не более 64 аплоадов за кадр и не более 2 мс на кадр.
- **Frustum Culling**: отсечение невидимых чанков до отрисовки.
- **Greedy Meshing**: радикальное сокращение числа вершин и draw calls.
