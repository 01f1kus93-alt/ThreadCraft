# ThreadCraft

**ThreadCraft** — многопоточный воксельный движок в стиле Minecraft, написанный на C++20 с использованием **raylib**. Основной упор сделан на производительность: генерация чанков, построение мешей и загрузка текстур выполняются параллельно в пуле потоков, а для оптимизации геометрии используется **Greedy Meshing** с кастомными GLSL-шейдерами.

---

## Возможности

### ⚙️ Многопоточное ядро
- **ThreadPool** — пул рабочих потоков с приоритетной очередью задач.
- Генерация чанков, построение мешей и выгрузка на GPU выполняются асинхронно.
- Количество потоков определяется автоматически (`hardware_concurrency`), минимум 4.

### 🏗️ Greedy Meshing
- Оптимизация геометрии: соседние грани блоков с одинаковой текстурой сливаются в один крупный прямоугольник.
- **Кастомный шейдер** (`greedy.vs` / `greedy.fs`) — UV-координаты и индекс текстуры передаются через vertex colors, что позволяет шейдеру правильно затайлить текстуру на объединённой грани без увеличения числа вершин.
- Прозрачные блоки (стекло, листва, вода) рендерятся отдельным проходом.

### 🌍 Процедурная генерация мира
- **Высота рельефа** — 2D-шум Перлина (определяет высоту точки).
- **Пещеры** — объёмный 3D-шум с двумя червеобразными проходами.
- **Слои**: бедрок (с шумовым искажением), глубинный сланец, камень, земля, трава/песок в зависимости от высоты.
- **Руды** (уголь, железо, золото) генерируются на основе шума.
- Размер чанка: 16×256×16 блоков.

### 🎮 Игровые механики
- **Свободный полёт** (FlyCamera) — WASD + мышь, Shift ускоряет, Ctrl замедляет.
- **Ломание блоков** — удержание ЛКМ (прогресс зависит от прочности, трещины `destroy_stage_0..9`).
- **Установка блоков** — ПКМ (ставится блок из выбранного слота hotbar).
- **Пипетка** — средняя кнопка мыши (копирует блок под прицелом в выбранный слот).
- **Инвентарь** — 9 слотов hotbar + 27 основных, drag&drop, ПКМ = половина/1, клик вне слотов = выброс.
- **Дропы** — сломанный блок выпадает предметом, подбирается при подходе.
- **Партиклы** — частицы ломания/удара, цвет = центр текстуры блока ±5 на канал.
- **Рэйкаст** — точное определение блока, на который смотрит игрок, с подсветкой рамкой.

### 🎨 Рендеринг
- **Texture Atlas** — все текстуры блоков объединены в единый атлас 16×16 тайлов.
- **Padding** — 8 px отступа между тайлами для устранения артефактов при mip-mapping.
- **Frustum Culling** — невидимые чанки не отправляются на отрисовку.
- **Оконный режим** — изменяемый размер окна.
- **HUD**: FPS, число чанков в памяти, координаты камеры, ID блока, график времени кадра.

## Сборка и запуск

### Зависимости
- **CMake** ≥ 3.20
- **raylib** (системная установка: `make install`, vcpkg или `apt install libraylib-dev`)
- **Компилятор C++20** (GCC 11+, Clang 14+, MSVC 2022+)

### Linux (Debian/Ubuntu)
```bash
sudo apt install cmake build-essential libraylib-dev
```

### Сборка
```bash
cd threadcraft
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
```

### Запуск
```bash
./minecraft_clone
```

## Управление

| Клавиша              | Действие                        |
|----------------------|---------------------------------|
| `W` `A` `S` `D`     | Перемещение камеры              |
| Мышь                | Вращение камеры                 |
| `Shift`             | Ускорение движения              |

| `Средняя кнопка`    | Скопировать блок под прицелом   |

| Колесо мыши         | Переключить слот hotbar         |
| `Esc`               | Меню паузы (или закрыть инвентарь) |

## Производительность

- **Автоматический пул потоков**: количество рабочих потоков = `max(4, hardware_concurrency - 1)`.
- **Приоритетная очередь задач**: чанки ближе к игроку обрабатываются раньше.
- **Асинхронная загрузка на GPU**: не более 64 аплоадов за кадр и не более 2 мс на кадр.
- **Frustum Culling**: отсечение невидимых чанков до отрисовки.
- **Greedy Meshing**: радикальное сокращение числа вершин и draw calls.
